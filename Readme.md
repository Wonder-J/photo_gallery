## 该项目已通过vercel部署到 [这里](https://photo-gallery-ebon-eight.vercel.app/)

- 搜索功能如下，输入想要搜索图片的文字，即可搜到自己想要的图片
![alt text](image.png)
- 登录功能在右上角，支持github与google登录，登录成功后会显示头像，点击头像会出现账号名称
![alt text](image-1.png)
![alt text](image-2.png)


本地启动项目：
```shell
## 安装依赖
pnpm i
## 配置环境变量，如获取pexel凭证，github与google的客户端key或者密钥
## 进入.env.local
## 本地启动服务
pnpm dev
```
